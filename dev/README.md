# Local development support

Root Compose runs the local dependencies and template API. `floci/bootstrap.sh` seeds the document bucket and synthetic provider secrets, then runs `events.sh` for messaging and `cognito.sh` for the public SPA client and four demo identities. Run all with `docker compose --profile offline run --rm bootstrap`. See [local development](../docs/local-development.md) for resource names, demo login configuration and safe reruns. [Shared workflow fixtures](fixtures/README.md) provide deterministic two-clinic data for mock UI/service development. Frontend/backend auth and full persistence checks remain separate tasks. Keep generated runtime data under ignored `.local/` or managed Docker volumes.
